# ASWAR 01 — Ultra-Luxury Residences

**Live site:** [https://aswar-residences-web.vercel.app](https://aswar-residences-web.vercel.app)

Marketing website for ASWAR International Development — Ras Al Khor, Dubai.

## Development

```bash
npm install
npm run dev
```

After changing `next.config.ts` or image sources, clear the Turbopack cache:

```bash
npm run dev:clean
```

## Production build

```bash
npm run build
npm start
```

## Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- Framer Motion
